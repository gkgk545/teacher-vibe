단계별 안내

연수 순서대로 따라 합니다. 프롬프트는 복사 버튼을 눌러 AI 대화창에 붙여 넣습니다.

① 도입

0:00–0:10
  1. 학생이 된 마음으로 강사의 시연 앱을 써 봅니다.
  2. 이 앱은 강사가 코드를 쓰지 않고 AI와 대화해서 만들었습니다.
  3. 오늘 두 시간 뒤에는 각자 만든 앱 하나가 게시판에 올라갑니다.

② 용어

0:10–0:25

AI 코딩 앱에서 자주 보는 말을 네 묶음으로 익힙니다.

  • 대화 단위: 세션, 컨텍스트, 토큰, 한도
  • 지침 단위: 작업 폴더, 지침 파일, 스킬
  • 저장·배포: git, 커밋, 저장소, 배포
  • 안전: 권한 승인, 모델 선택, 개인정보

용어 정리 한 화면으로 보기

③ 준비

0:25–0:35

1. 도구를 설치하고 로그인합니다

학교 Google Workspace 계정은 관리자가 막아 두었을 수 있습니다. 개인 Gmail을 씁니다.

2. 작업 폴더를 만들고 엽니다

바탕화면에 빈 폴더(예: 내앱)를 하나 만들고, 도구에서 그 폴더를 엽니다. 오늘 만드는 모든 파일이 이 폴더에 쌓입니다.

3. AI에게 스킬 설치를 맡깁니다

설치가 안 되면 예비 자료에서 내 도구에 맞는 스킬 묶음을 내려받아 작업 폴더에 풉니다.

④ 기획

0:35–0:55
  1. 바로 만들어 달라고 하지 않습니다. grill-me가 빈틈을 하나씩 묻게 합니다.
  2. 질문마다 AI가 추천 답을 함께 줍니다. 맞으면 그대로, 다르면 내 답을 적습니다.
  3. 대화가 끝나면 기획서를 PRD.md 파일로 남깁니다.

학생 이름·성적·생활기록부 원문은 넣지 않습니다. 예시 자료는 지어낸 이름으로 만듭니다.

쉬는 시간

0:55–1:05

배포에 쓸 두 곳에 가입하고 로그인해 둡니다.

GitHub 가입 Cloudflare 가입

가입이 늦어지면 ⑥ 배포를 건너뛰고 HTML 파일을 게시판에 올리면 됩니다.

⑤ 제작

1:05–1:35

카파시 원칙 네 가지

  1. 코딩 전에 생각합니다
  2. 단순하게 만듭니다
  3. 요청한 곳만 고칩니다
  4. 목표로 검증합니다

만들고, 시험하고, 한 줄씩 고칩니다

  1. 기획서를 바탕으로 만들어 달라고 요청합니다.
  2. 성공하는 입력, 실패해야 하는 입력, 애매한 입력을 하나씩 넣어 봅니다.
  3. 어긋난 곳은 실패한 입력, 기대한 반응, 고칠 규칙 한 줄로 알려 줍니다.
  4. 기능 하나가 되면 커밋합니다. 망가지면 커밋으로 되돌립니다.

⑥ 배포

1:35–1:50 시간이 없으면 건너뜁니다
  1. GitHub 저장소를 만들어 작업 폴더를 연결합니다.
  2. Cloudflare에서 그 저장소를 배포해 주소를 받습니다.

건너뛸 때는 앱의 HTML 파일을 ⑦에서 게시판에 바로 올립니다.

⑦ 공유·마무리

1:50–2:00
  1. 공유 게시판에 들어가 연수장에서 안내한 입장 코드를 넣습니다.
  2. '앱 올리기'를 눌러 이름, 앱 이름, 교과·학년, 한 줄 소개를 적고 배포 주소나 HTML 파일을 올립니다.
  3. 동료의 앱을 열어 써 보고 댓글을 남깁니다. 선택
  4. 집에서는 같은 폴더를 다시 열고 새 세션으로 이어 갑니다.
